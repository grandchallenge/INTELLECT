# Agent instructions

INTELLECT is the constitutional-policy repository of the Grand Intellect. It
has no mathematical certification authority: MATHCERT alone renders bounded
mathematical dispositions through accepted routes. AETHER remains the
production semantic authority described in Article IX.

Treat `CONSTITUTION.md` as supreme law, effective amendments as its lawful
supplements, and constitutional commentary as nonbinding interpretation.
`gcl-standards` is a subordinate registry and publication repository.

Under the effective authority schedule, one Codex system may staff multiple
non-reserved roles through distinct, exact-subject logical audit passes.
Routine bounded and non-reserved substantive work may proceed through protected
merge and readback without a fresh human action or identity hand-off. A system
that authored a subject must use a declared non-authoring, read-only mode when
acting as Adversary or Referee; mutation invalidates that pass.

For authorized GitHub work, transport capability is not an authority boundary.
Use a connected GitHub action when it exposes the required operation. If the
connected action surface does not expose an otherwise authorized GitHub
operation, do not stop merely because of that connector gap: use authenticated
`gh`/GitHub API execution directly when available. If direct CLI execution is
not available in the current environment, provide one complete, copy/pasteable,
self-contained `gh`/bash script that checks prerequisites and live state,
performs the mutation through the required protected route, and reads back the
result. Do not substitute manual GitHub UI instructions merely because a
connector endpoint is missing when `gh` or the GitHub API can express the
operation. Fallback scripts must preserve the caller's interactive shell and
must not use shell-kill abort patterns such as parent-shell `set -e`, `exit`,
`kill`, `exec`, or terminating traps. A connector or tooling limitation is a
transport defect, not a reason to weaken protection, authority, evidence, or
claim boundaries.

Agents may not ratify a constitutional amendment, manufacture Human Steward
authorization, self-certify a mathematical claim, exercise reserved authority,
bypass protected controls, or write directly to protected branches. Follow
`GI-STEWARD-0003` only when it is selected by the protected schedule.
