# Roadmap

## WP-0: Constitutional foundation — implemented

Deliver the event model, offices, lifecycle, gates, agent boundary, schemas, test fabric, AETHER adapter, tests, and governing documentation.

Exit criterion: one complete deterministic cycle passes locally and all missing obligations fail closed.

## WP-1: Live AETHER closure

Deliver a reproducible AETHER launch configuration, schema registration and activation, namespace and token policy fixtures, live append/history/replay tests, cut-aware reports, and one resolved trace handle.

Exit criterion: a complete INTELLECT cycle is reconstructible solely from a live AETHER journal.

## WP-2: Semantic gate compilation

Deliver AETHER predicates for phase evidence and office approvals, derived `gate_ready` and `gate_blocked` relations, application conformance tests, and proof-trace rendering.

Exit criterion: at least three phase gates are authoritatively derived by AETHER with application equivalence.

## WP-3: Artifact and memory fabric

Deliver artifact sidecar registration, digest-bearing evidence, retrieval records subordinate to journal facts, memory compression, supersession workflows, and disposal recovery tests.

## WP-4: Lease-governed execution

Deliver Executor claims, heartbeat-backed leases, epoch fencing, stale-result rejection, accepted outcomes, and handoff reports.

Exit criterion: an Executor cannot publish an accepted outcome after losing authority.

## WP-5: Model-provider agent runtime

Deliver provider-neutral `OfficeAgent` adapters, structured-output validation, office-specific tool capabilities, prompt-injection isolation, replay metadata, and human checkpoints.

## WP-6: Grand Challenge campaign exemplar

Apply the system to the Union-Closed programme through Axiomatist definitions, Cartographer dependencies, Verifier obligations, Adversary failures, Formalist boundaries, Amanuensis ledgers, Referee criteria, computational evidence, disposal, and residual frontier.

## WP-7: Operator cockpit

Deliver live phase and gate views, unresolved obligations, evidence lineage, temporal cut comparison, disposal queue, and human authorization surfaces.

## WP-8: Constitutional hardening

Deliver risk profiles, policy model checking, adversarial governance simulations, migration tooling, constitutional versioning, and distributed authority-partition posture.
